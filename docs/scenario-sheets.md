# レンガ村の物語　シナリオの書き方（スプレッドシート）

芽美（物語とゲーム設計）向けの、スプレッドシートへの登録形式です。
物語本文・セリフ・選択肢・分岐条件・アイテム・エンディングは、すべてこの形式で登録します。
**CSV（カンマ区切り）または表**で渡してもらえれば、そのまま貼り付けられます。

> **表記の決まり（2026-10-18 確定）**
> - 英語の村の名前は **Brick Village** に統一（Renga Village は使わない）。
> - ひらがなモードは漢字を使わず、**カタカナはそのまま使う**（例：エスパー、ページ、レンガむら）。
> - 住人の名前は「住人」シートの表記に合わせる（エスパー、ミミ、リリィ、ルーク、ニコ、ハル、アリカ、ヌール、モック、じいじ）。

> **列の正式な順番（ひらがな・English の列を含む）は `docs/sheet-columns.md` と記入用の雛形 `docs/scenario-template.xlsx` を見てください。** このページの表は書き方の説明用で、ひらがな・English の列は省略しています。

- ID（施設ID・場面ID・アイテムIDなど）は、半角英数字と `_` で書いてください（例：`well_01`）。
- 1つのイベントの中身には、同じ `event_id` を付けます（例：`iw2026xmas`）。次回のイベントは別の event_id にします。

### 住民名の差し込み

セリフの中に `{name}` と書くと、住民登録したニックネームに置きかわります。

| 話す住人ID | セリフ（シートに書く文） | 画面での表示（住民名が「さとし」のとき） |
|---|---|---|
| mimi | こんにちは、{name}！ レンガ村へようこそ！ | こんにちは、さとし！ レンガ村へようこそ！ |

- `{住民名}` と書いても同じです。
- 選択肢の文、ARボタンの文字、ことばに正解したときのメッセージでも使えます。
- 登録項目のほかの値も `{項目ID}` で差し込めます（例：`{color}` → 好きな色、`{friend}` → いちばん会いたい住人の名前）。
- 書き間違い（登録項目にないもの）は、`{…}` のまま表示されるので気づけます。

### 画面の見え方（絵本形式・文字が基本）

- 1行のセリフが、1画面（1ページ）になります。画面には、住人の顔イラストと名前、セリフが出て、「つぎへ」で進みます。「◀ もどる」で前のページを読み返せます。
- **1行は60文字以内を目安**に短く書いてください。60文字をこえると、文の切れ目（。！？）で自動的にページが分かれます。
- 音声は現在ありません。物語の内容は、すべて文字で伝わるように書いてください（音を出さない会場でも理解できること）。
- 効果音と動きは、アプリが自動で付けます：ひみつのことばの正解、アイテムをもらったとき（大きく表示）、エンディング（「おしまい」の演出）。効果音は画面右上の 🔊 で消せます。
- 「音声ファイルURL」列は将来のための空欄です。音声を用意したときに、ファイルのURLを入れると、そのページで再生されます（今は空欄のままにしてください）。

## 条件の書き方（「条件」「地図に出る条件」「表示する条件」の列）

`；`（または `;`）で区切ると「すべて満たしたとき」になります。

| 書き方 | 意味 |
|---|---|
| `再訪` | 前の開催日にも来た住民（**前回のイベントへの参加も含む**） |
| `初来訪` | はじめて来た住民 |
| `前回参加` | 別のイベント（前回のinnocent world）に参加したことがある |
| `今回再訪` | 同じイベントの前の開催日にも来た住民（例：1日目と2日目の両方に参加） |
| `今回初来訪` | このイベントでははじめて来た住民（前回のイベントに参加していても該当） |
| `2日目` | 開催2日目 |
| `アイテム:key` | アイテムを持っている（アイテム名でも可） |
| `記録:saw_light` | その記録がある |
| `記録なし:saw_light` | その記録がない |
| `勇気>=2` | ポイントが2以上（ポイント名でもIDでも可） |
| `読了:well` | その施設の物語を読み終えた |
| `読了数>=3` | 読み終えた施設の数が3以上 |

例：`今回再訪；アイテム:key` … 1日目にも来ていて、鍵を持っている住民だけ

両日参加者向けには `今回再訪`、2日目だけ来た人向けの導入には `2日目；今回初来訪` を使います。
（`初来訪` は前回のイベントに参加した人を含まないので、2日目のみの導入には使わないでください）

書き方が読み取れない条件は「満たさない」扱いになります（書き間違いに気づけるように）。

## ポイントの書き方

`勇気+1，やさしさ+2` のように、`，` で区切ります。減らすときは `勇気-1`。
