## 1. 物語の中のパン屋
- 施設：**ニコのパン屋さん**（id `bakery`）。説明「焼きたてのパンの香りがする小さなお店。」施設の色：屋根 赤（#d9534a）、壁 クリーム（#fff1d6）
- 場面：`bakery_01` → 選択 → `bakery_02a`（ミミに聞く）または `bakery_02b`（先に焼いてみる）。背景はすべて `bakery`（1枚）
- 登場する住人：**ニコ**（ほとんどのセリフ）、**ミミ**（`bakery_02b` で1行）。立ち絵は話す人が1人ずつ画面の中央に出る
- 手に入るもの：**やさしさのパン**（`kind_bread`）「ニコが相手の気持ちを考えて作ったパン。」

## 2. 背景に必要な物（店の中・昼）
- **レンガのかまど（オーブン）**：パンを焼く場所。火が小さく見える
- **窓辺の棚**：焼きたてのパンが並ぶ窓（窓の外に村が少し見える）
- **作業台**：丸めたパン生地、粉、めん棒（「生地を丸めながら」）
- **壁の空いた所**：小さな紙を貼る場所（コルクボードか木の壁）。**紙と文字は描かない**（アプリが3言語で重ねる）
- あってもよい物：パンかご、木の棚、小さなスープ鍋（「温かいスープ」の話につながる）、花柄のタイルやテキスタイル
- 雰囲気：温かくて、いいにおいがしそうな小さなお店。北欧テキスタイル風の花柄（カーテン・タイル・布）
- **描かないもの**：住人（ニコ・ミミ）、文字（看板・紙・値札も無地）、うさぎのモチーフ

## 3. 画面の配置（座標は 400×800 の目安。画像では3倍）
| 範囲 | 何を置くか | 理由 |
|---|---|---|
| 縦 0〜56 | 天井・梁・吊るしたドライフラワーなど（細かすぎない物） | ボタンが重なる |
| 横110〜290・縦90〜425 | すっきりした壁や窓の明るさ | ニコ・ミミが立つ場所 |
| 左右（横30〜110・290〜370）・縦100〜420 | **かまど**（片側）と**パンの並ぶ窓辺の棚**（反対側） | 立ち絵の横に見える＝会話中も「パン屋」とわかる |
| 横120〜280・縦420〜530 | **作業台**（生地・粉）の手前の端 | 立ち絵の足もと。地の文の場面で全体が見える |
| 壁の空いた所（横300〜360・縦250〜320 あたり） | 紙を貼るための無地のボード | アプリが「まず、聞いてみる」の紙を重ねる |
| 縦530〜800 | 床・作業台の下 | 文章の枠が重なる |
| 左右 0〜30・370〜400 | 大事な物を置かない | 細長いスマホで切れる |

- ミミも立つので、立ち絵の後ろに白すぎる物（白い壁一面、白いのれん）を置かない
- ニコの立ち絵は横幅がやや広い。かまどと窓辺の棚は、立ち絵の外側に収まるように

- `scenes.bakery = {far: 'art/scenes/bakery/far.webp', focus: 作業台の手前の端, floor: 作業台の上の面}`
