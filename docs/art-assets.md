# 正式なイラスト素材の作り方と差し替え

> 画風は docs/art-direction.md（北欧・スウェーデンテキスタイル風）に従う。原画は1枚に1つの物・無地の背景で描き、切り抜きと配置は Claude 側で行う。

状態：差し替え口は手元の開発ブランチに用意ずみ（本番には未反映）

素材が届いたら `story/art/` に置き、`story/art/manifest.js` にパスを書くだけで、その部分が画像に置きかわります。
空欄の部分は、今までどおりアプリが描く仮の絵のままです（1枚ずつ順番に差し替えられます）。

## 1. 部屋と絵本（導入と帰還で共通の、同じ部屋・同じ構図）

**すべて同じキャンバス：1200×2400 ピクセル（縦長 1:2）**。位置合わせのガイド：`story/art/guide-room.png`

| ファイル（例） | 中身 | 透明 |
|---|---|---|
| `art/room/base.webp` | 部屋のぜんたい：壁・床・本棚・ベッド・机・ランプ・**窓の中の夜空と月と星**（窓わくは描かない） | なし |
| `art/room/lace_left.png`・`lace_right.png` | 薄いレースのカーテン（左半分・右半分）。閉じた状態で描く（開く動きはアプリが付ける） | あり |
| `art/room/frame.png` | 窓わく・横木・窓の下の段・厚手のカーテン（窓の外の住人より手前に重なる部分） | あり |
| `art/book/closed.png` | 机の上に立てた閉じた絵本（表紙。正式ロゴはそのまま） | あり |
| `art/book/clasp.png` | 留め金だけ（外れて落ちる動きはアプリが付ける） | あり |
| `art/book/open.png` | ひらいた絵本（左のページにレンガ村の絵） | あり |

**ガイドの決まりごと**（座標は 400×800 の目安。実寸は×3）
- 窓の開口：上が半円のアーチ形、横 128〜272・縦 80〜294（緑の点線）。この形・位置で描く（窓の外の住人とレースがここに重なる）
- 絵本：横 140〜262・縦 292〜448（紫の点線）。留め金は 横250・縦383 あたり（黄色の円）
- 机の天板：縦 446 あたり。記念の品は 横282・縦418 あたり（水色の点線）
- 白い点線：絵本から現れた住人が立つ場所（住人の絵が重なるので、細かい物は置かない）
- 上の黄色の帯：ボタンが重なる（空・壁だけに）
- 下の青い帯：文章の枠が重なる（床など、なくてもよい部分）
- 左右の赤い帯：細長いスマホでは切れる（大事な物は置かない）
- 夜。ベッドに入る前に絵本を読んでいる。窓の外に月と星、机にランプ。住人の絵（ふわっと塗った、太い黒の線のない絵）と同じ塗り方にそろえる

## 2. 記念の品・もちもの

| ファイル（例） | 中身 | 大きさ |
|---|---|---|
| `art/items/old_bookmark.png` | 古いしおり（中央広場の絵） | 正方形 800×800・透明あり |

manifest の `items` に `old_bookmark: 'art/items/old_bookmark.png'` のように書くと、机の上・大きく見せる場面・もちものの詳しい説明の3か所が画像になります。

## 3. 正式ロゴ

`logo: 'art/logo.png'`（透明あり PNG または SVG。改変しない）。
絵本の表紙の画像（`book/closed`）がまだのあいだは、仮の表紙にロゴをそのまま載せます。

## 4. 住人の画像
`characters2/<住人ID>.png`。デザインは変えずに高解像度化（縦1200ピクセル以上・透明あり）したものに、同じファイル名で差し替える。
追加のポーズ（例：手を差しのべる）は、決まったら差し込み口を足す。

## 5. 形式
- 写真のような細かい絵は WebP（画質80前後）、透明が必要なものは PNG（または透明つき WebP）
- 部屋ぜんたいで合計1MB前後が目安（読み込みが重くならないように）
