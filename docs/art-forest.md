状態：仕様（未制作）。画風は docs/art-direction.md、共通の決まりごとは docs/art-arrival.md・story/art/guide-scene.png。

## 1. 物語の中の森
- 施設：**モックとハルの森**（id `forest`）。説明「木漏れ日の道と、古い木の橋がある森。」施設の色：緑（#4f9a4a）、木の茶（#8a5a2a）
- 場面：`forest_01` → 選択 → `forest_02a`（ハルの気持ちを聞いて約束を考え直す）または `forest_02b`（風が弱くなるまで待つ）。背景はすべて `forest`（1枚）
- 登場する住人：**モック**と**ハル**（交互に話す。立ち絵は話す人が1人ずつ中央に出る）
- 手に入るもの：**森の紙切れ**（`forest_scrap`）「森で見つけた、言葉のかけらが残る紙。」

| 場面 | 背景にかかわる文 |
|---|---|
| forest_01 1行目（地の文） | 「森の奥で、古い木の橋が風に揺れていました。向こう岸には、小さな花が咲いています。」 |
| forest_01 3行目（ハル） | 「今日は風が強いから……少し怖いんだ。」 |
| forest_01 6行目（地の文） | 「モックは橋を見つめています。ハルは、そっと足を止めました。」 |
| forest_02a 2〜3行目 | ハル「今日は川のそばで遊ぼう」／「二人は川辺に座りました。向こう岸の花が、風に揺れています。」 |
| forest_02b 2行目（地の文） | 「二人は木の下で待ちました。でも、風はなかなかやみません。」 |
| forest_02b 5〜6行目 | 「橋の向こうから、風に乗って紙の切れ端が飛んできました。」ハル「あれ？ 『ずっと』って書いてある。」 |

## 2. 背景に必要な物
- **川**：森の奥を横切る小川。**こちら岸と向こう岸の両方が見える**
- **古い木の橋**（主役）：**川をまたいで、両岸にきちんと架かっている**。少し古くて頼りない（手すりのある素朴な木の橋）。風に揺れているように見える角度・傾き
- **向こう岸の小さな花**：橋を渡った先の花畑（物語の目的地）
- **こちら岸**：木漏れ日の小道、川辺の草地（「川辺に座りました」）、大きな木（「木の下で待ちました」）
- 風：木の葉や草が一方向になびく、花びらや葉が少し舞う（風の強さが伝わる）
- **注意（以前の指摘）**：木や岩を川の上（水の上）に置かない。橋の両端は必ず岸の上
- 雰囲気：明るい森。風は強めだが怖くない（木漏れ日・やわらかい緑）
- **描かないもの**：住人（モック・ハル）、文字、紙切れ（アプリが飛ばす）、うさぎのモチーフ

## 3. 画面の配置（座標は 400×800 の目安。画像では3倍）
| 範囲 | 何を置くか | 理由 |
|---|---|---|
| 縦 0〜56 | 木の葉の天井・空（細かすぎない） | ボタンが重なる |
| 横110〜290・縦90〜425 | 森の奥の明るさ・遠くの木々（すっきり） | モック・ハルが立つ場所 |
| 縦250〜420 の左右どちらか（例：右 横250〜370） | **橋と向こう岸の花**（立ち絵の横・後ろに橋が見える） | 会話中も「橋を渡る約束」がわかる |
| 縦380〜470 の横いっぱい | **川**（立ち絵の足もとの先を横切る） | 地の文の場面で川と橋の全体が見える |
| 横120〜280・縦460〜530 | こちら岸の草地・小道（立ち絵の足もとの地面） | 住人が川の上に浮かないよう、足もとは岸 |
| 縦530〜800 | 小道・草花の続き | 文章の枠が重なる |
| 左右 0〜30・370〜400 | 大事な物を置かない | 細長いスマホで切れる |

- 立ち絵の足もと（目安 縦425〜460）は**こちら岸の地面**にする（川の水の上に立って見えないように）
- ハルの立ち絵は背が低め、モックは大きめ。どちらも中央に立つ
