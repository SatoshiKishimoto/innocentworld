# 「レンガ村に到着」の背景（北欧テキスタイル風）仕様

状態：仕様の整理（未制作・未実装）。画風は docs/art-direction.md に従う。位置合わせのガイド：story/art/guide-scene.png

## 1. 今の到着画面
- 場面：『消えた最後のページ』の `intro_01`（背景名 `meadow`）。導入（部屋）の光が消えた直後に表示
- 絵：story/scenes.js の `meadow()`。コードで描いた図形（空・雲・丘・家並み・大きな絵本の門・BRICK VILLAGE の札・レンガの道・花）
- 表示：縦長 400×800 の座標で描き、画面の上をそろえて、はみ出た部分を切る（上は必ず見え、下と左右が切れる）
- 重なるもの：上にボタン、中央にセリフを話す住人の立ち絵（エスパー）、下に文章の枠
- 続く場面 `intro_02` は背景 `plaza`（中央広場）→ 次の制作対象

## 2. 画面の決まりごと（座標は 400×800 の目安。画像では3倍）
| 範囲 | 何が重なるか | 描くもの |
|---|---|---|
| 縦 0〜56 | ボタン | 空だけ |
| 縦 56〜130 | ― | 空・雲・遠くの丘 |
| 横110〜290・縦90〜425（白枠） | 住人の立ち絵 | 顔の後ろはすっきり（空や遠くの景色）。細かい物を置かない |
| 縦130〜444（緑枠） | ― | **主役**：村の入口と赤レンガの家並みを、住人の左右と奥に |
| 縦444〜530 | 小さいスマホでは文章の枠 | 地面・石だたみの道（ふつうのスマホでは見える） |
| 縦530〜800 | 文章の枠 | 地面の続き（隠れてよい） |
| 左右 0〜30・370〜400 | 細長いスマホで切れる | 大事な物を置かない |

到着の場面は昼（明るい空）。夜の部屋から光を抜けて着くので、空の色で「別の世界に来た」ことが伝わるとよい。
**文字は絵に描かない**（3言語で表示するため）。看板は無地の板にしておく。

## 3. 必要なレイヤー（すべて 1200×2400・同じ位置合わせ）
| ファイル名 | 中身 | 透過 | 必須 |
|---|---|---|---|
| `art/scenes/meadow/far.webp` | 空・雲・遠くの丘・遠くの家並み | なし | ○ |
| `art/scenes/meadow/mid.png` | 村の入口（門）・赤レンガの家並み・石だたみの道・地面 | あり（空の部分は透過） | ○ |
| `art/scenes/meadow/near.png` | 手前の花・草（左右と下のふちだけ） | あり | 任意 |
| `art/scenes/meadow/clouds.png` | 雲だけ（ゆっくり流す） | あり | 任意 |

- 1枚の絵（far だけ）でも表示できる。分けると、雲がゆっくり流れる・手前の花がわずかに揺れるなどの動きを付けられる。
- 動かしたい部品（風車の羽根・旗など）を足すときは、同じ形で別のファイルにする。

## 4. 推奨サイズと形式
- キャンバス：1200×2400（縦長1:2）。原画は長い辺1500px以上で、1枚に1つのレイヤーを描く（並べた見本は使わない）
- 原画の背景：far は全面に描く。mid・near・clouds は、白か黒の無地の背景で描けば、切り抜きと配置は Claude 側で行う
- 形式：透過なしは WebP（画質85前後）、透過ありは PNG。1場面で合計1MB前後が目安

## 5. アプリ側の対応（原画が届いたら Claude が行う）
- story/art/manifest.js に `scenes.meadow` の差し込み口を足す（未設定のあいだは今のコードの絵）
- 住人の色味調整（characterTone）は外の場面にも合わせて確認する
- 390×844 と 375×667 で、立ち絵・文章の枠・主役の見え方を確かめる

## 6. 今後の統一（同じ仕様で順に）
`plaza`（中央広場）→ `well`（井戸）→ `bakery`（パン屋）→ `forest`（森）→ `clock`（時計台）→ `library`（図書館）
室内（パン屋・時計台・図書館）は、far を「部屋の奥の壁」、mid を「家具・設備」と読みかえる。
村の地図の画面も、最後に同じ画風にそろえる。
