# innocent world デザイン方針（2026-10-22 決定）

## コンセプト
**「子供の頃の気持ちを思い出せる場所」**
子供には冒険を、大人には懐かしさを。懐かしさ・安心感・好奇心・優しさを感じられること。
判断基準は「高画質かどうか」より **「この世界に入ってみたいと思えるか」**。

## 画風：スウェーデンの伝統的なテキスタイルを取り入れた北欧絵本風
- 布にプリントしたような柔らかな質感
- 手描きの花・葉・木・鳥・星の素朴な模様
- 少し不揃いで温かみのある輪郭
- 切り絵・版画・ガッシュのような平面的な塗り
- 子供が親しみやすい、単純化された形
- 避けるもの：安価なベクター素材のような無機質な図形／写実的な陰影／過剰な金装飾／CG的な光沢
- 特定の作家・ブランドをまねず、伝統的な図案の特徴を取り入れた独自の世界観にする

## 色
- 基本色：くすんだブルー、森のグリーン、クリーム色、温かい赤、マスタードイエロー
- 夜：深い青の空に、柔らかな黄色の月と星。怖い夜ではなく、子供が安心して眠れる夜

## 適用範囲
夜の部屋・絵本・小物から始め、今後のレンガ村の建物・自然・室内・アイテムにも同じ方針を使う。
エスパー・ミミなど住人の設定と、見分けられる特徴は変えない。背景だけが別の作品に見えないよう、住人との調和を確かめる。

## 進め方
1. **夜の部屋を1枚**だけ作り、新しい画風を承認してから、ほかの素材に広げる
2. 画像生成は **1枚につき1つの物**。並べたコラージュは使わない。高解像度の独立した原画（長い辺1500px以上）
3. 切り抜き・透過・配置・アプリでの確認は Claude 側（組み立て手順：v11 の build_v11.py と同じ）
4. v11 で確かめた座標・レイヤー構造・演出はそのまま（docs/art-assets.md）
5. 390×844 と 375×667 で表示を確かめる。最終承認まで本番アプリ・本番DBには反映しない

## 原画の頼み方（6枚・1枚ずつ）
| # | 描くもの | 背景 | 注意 |
|---|---|---|---|
| 1 | 夜の部屋（本棚・ベッド・木の机・ランプ・横木のないアーチ窓。窓の外に月・星・レンガ村の灯り） | 全面に描く | **縦長1:2**。窓は画面の上のほう中央。**机の上に絵本を置かない**。窓辺にうさぎのぬいぐるみを置かない |
| 2 | 閉じた絵本（表紙の中央にロゴ・題字用の余白。留め金なし） | 真っ白な無地 | 本だけ |
| 3 | ひらいた絵本（左のページにレンガ村） | 真っ白な無地 | 本だけ |
| 4 | 留め金（素朴な金具。宝飾品のようにしない） | 真っ白な無地 | 留め金だけ |
| 5 | 古いしおり（中央広場の絵・房つき） | 真っ白な無地 | しおりだけ |
| 6 | レースの布（刺しゅうのような素朴な模様。正面から見た平らな布） | **真っ黒な無地** | 布だけ |

背景は透過を表す市松模様ではなく、本当に1色の無地にする（市松模様は絵として描かれてしまい、抜けない）。

## 住人との調和について（気をつけること）
今の住人の絵（characters2）は、なめらかな塗りに光沢のあるアニメ調。
平らなテキスタイル調の背景に置くと、住人だけが浮いて見えるおそれがある。
→ 夜の部屋の1枚目ができた時点で、エスパーとミミを実際に重ねて確かめ、
　必要なら「特徴は変えずに、住人の絵も同じ画風で描き直す」かどうかを決める。
