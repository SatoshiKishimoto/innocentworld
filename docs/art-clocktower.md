状態：第3稿を正式採用（2026-10-23）。文字盤は今の構図のまま、針は10時（左上向き）で止まっている。画風は docs/art-direction.md、共通の決まりごとは docs/art-arrival.md・story/art/guide-scene.png。
物語・設定は変更しない。以下は『消えた最後のページ』の今のシナリオだけから整理した（シナリオにない設備・設定は足さない）。

## 1. 物語の中の時計台
- 施設：**ルークとアリカの時計台**（id `clock`）。説明「村の真ん中に立つ時計台。針はある時刻で止まったまま。」施設の色：青（#5a6ab8）、クリーム（#f3e2c0）
- 場面：`clock_01` → 選択 → `clock_02a`（鐘を鳴らして声を確かめる）または `clock_02b`（古い帳面から止まった日の記録を探す）。背景はすべて `clock`（1枚）
- 登場する住人：**ルーク**と**アリカ**（交互に話す。立ち絵は話す人が1人ずつ中央に出る）
- 手に入るもの：**時計の歯車**（`clock_gear`）「止まった時計台で見つけた小さな歯車。」どちらの分かれ道でももらえる

## 2. 背景に描く物（シナリオに出てくる物だけ）
| 物 | シナリオの根拠 | 描き方 |
|---|---|---|
| **たくさんの歯車**（主役） | 「たくさんの歯車が静かに止まっていました」 | 大小の木と真ちゅうの歯車が、壁や軸にかみ合っている。止まっている（静か）。素朴な北欧の木工風 |
| **時計の文字盤（内側から見た裏側）** | 「針だけが同じところで止まってしまう」「針が一瞬だけ動きました」 | 塔の壁の丸い窓のような文字盤を内側から。**針は描かない**（アプリが重ねて、一瞬だけ動かす）。文字盤の数字も描かない（裏側なので模様だけ、またはぼかす） |
| **鐘** | 「鐘が鳴るたび」「ルークがそっと鐘を鳴らしました」 | 上のほうに吊るされた鐘（金色・素朴）。鳴る動きと光はアプリが重ねる |
| **古い帳面** | 「古い帳面には、時計の点検日がずらりと並んでいました」 | 作業机の上に開いた帳面。**文字は描かない**（罫線だけ、または読めない模様） |
| **塔の内部・扉** | 「時計台の扉を開けると」 | 木の床、塔の壁（レンガ・木の梁）、小さな窓。扉は描いてもよい（なくてもよい） |

**描かないもの・足さないもの**
- 住人（ルーク・アリカ）、文字（帳面・文字盤・看板）、時計の針、鐘の光や音の表現（動く演出はアプリ側）
- **振り子は、シナリオに出てこないため描かない**（必要なら芽美のシナリオに書かれてから足す）
- 落ちている小さな歯車（アイテム「時計の歯車」）は、もらう演出がアプリにあるので描かない
- うさぎのモチーフ

雰囲気：明るい昼の光が小窓から差しこむ、木と真ちゅうの温かい機械室。止まっていて静か。こわい・暗い印象にしない。

## 3. 画面の配置（座標は 400×800 の目安。画像では3倍）
| 範囲 | 何を置くか | 理由 |
|---|---|---|
| 縦 0〜56 | 梁・天井（細かすぎない） | ボタンが重なる |
| 横110〜290・縦90〜425 | 塔の壁・やわらかな光（すっきり） | ルーク・アリカが立つ場所。顔の後ろに細かい歯車を置かない |
| 横30〜120・縦60〜220（左上） | **鐘** | 立ち絵の横に見える。鳴る演出をここに重ねる |
| 横250〜370・縦100〜240（右上） | **文字盤の裏側**（丸） | 立ち絵の横に見える。針はアプリがここに重ねる。中心の位置を正確にしたい |
| 左右（横30〜110・290〜370）・縦220〜430 | **歯車**（大小） | 会話中も「時計台の中」とわかる |
| 横120〜280・縦420〜530 | **作業机と開いた帳面**（手前の端） | 立ち絵の足もとの前。地の文の場面で全体が見える |
| 縦530〜800 | 木の床 | 文章の枠が重なる |
| 左右 0〜30・370〜400 | 大事な物を置かない | 細長いスマホで切れる |

- ルークは背が高め、アリカはやや小さめ。どちらも中央に立つ
- 文字盤の中心と半径が分かるよう、丸ははっきり描く（針をぴったり重ねるため）

## 4. アプリ側の演出（原画が届いたら Claude が行う。背景には描かない）
- **針**：文字盤の裏側に、止まった針を重ねる。`clock_02b` 5行目「時計の針が、一瞬だけ動きました」で、針が一瞬だけ動いて止まる（シナリオの文から判断）
- **鐘**：今も「鐘」「鳴」を含む行で鐘の音が鳴る（`clock_01` 5行目・`clock_02a` 1行目）。`clock_02a` 1行目で、鐘が揺れて金色の光が部屋に広がる演出を控えめに重ねる
- 位置：`scenes.clock = {far, focus: 作業机の手前の端, floor: 作業机の奥の端, dial: 文字盤の中心と半径, bell: 鐘の位置}`
- 390×844 と 375×667 で、ルーク・アリカを重ねて2つの分かれ道を確認
