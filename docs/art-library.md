## 2. 背景に描く物（シナリオに出てくる物だけ）
| 物 | シナリオの根拠 | 描き方 |
|---|---|---|
| **図書館の奥**（本棚） | 「図書館の奥には」「図書館」 | 木の本棚に古い本が並ぶ、静かな奥の部屋。本の背に文字は描かない |
| **最後のページだけがない絵本**（主役） | 「最後のページだけがない絵本が置かれていました」 | **部屋（導入）で開く絵本と同じ本**（主催者の決定 2026-10-23）。表紙の色・装飾・装丁を story/art/book/closed.png・open.png にそろえる。机の上に**最後のページがない状態で開かれている**。**ページに文字も絵も描かない**（無地か、読めないやわらかな模様）。破れた跡・ちぎれた跡は描かない（シナリオは「破れた」ではなく「ない／消えた」） |
| 机（絵本を置く場所） | 「置かれていました」 | 素朴な木の閲覧机。絵本の左右に、何も置かない空いた面を残す（記録・手紙・しおりをアプリが重ねるため） |

**描かないもの・足さないもの**
- 住人（リリィ・ヌール）、文字（本の背・看板・紙）
- **古い記録・手紙・しおり**：場面の中で開いたり落ちたりする物なので、背景には描かない（アプリが場面に合わせて重ねる。文字は3言語）
- 涙の跡、言葉のかけらの光など、動きや演出にあたるもの
- シナリオに出てこない仕掛け・道具（地球儀・天球儀・望遠鏡・砂時計・魔法の光る本など）。うさぎのモチーフ
- 本棚・窓・机・いす・ランプ・じゅうたんなど、図書館としてふつうの家具は描いてよい（ただし主役の絵本より目立たせない）

雰囲気：明るい昼の光がやわらかく差しこむ、静かで温かい図書館。北欧テキスタイル風の花柄（カーテン・じゅうたん・本棚の飾り）を施設の青とクリームで。こわい・暗い印象にしない（ヌールは手紙を読むのが「少し怖い」が、場所はやさしく）。

## 4. アプリ側の演出（原画が届いたら Claude が行う。背景には描かない・すべて控えめ）
シナリオの文に書かれた出来事だけ。シナリオにない内容は足さない。3つとも採用（主催者 2026-10-23）。
- **しおり**：`library_02a` 5行目「ページの間から…しおりが落ちました」で、絵本のページの間から古いしおり（今あるアイテムの絵）が机の上へ落ちる
- **古い記録**：`library_02a` 2〜3行目で、机の空いた面に古い紙を重ね、「かならず戻ってきて」に線が引かれ、その下に小さく「自分で決めていい」（各言語の文。セリフの「」から取る）
- **手紙**：`library_02b` 1行目「手紙を開きました」で、机の空いた面に手紙が開く。にじんだ跡を少し
- 位置：`scenes.library = {far, focus: 絵本の手前の端, floor: 机の奥の端, book: 絵本のページの範囲, desk: 空いた机の面}`
- 390×844 と 375×667 で、リリィ・ヌールを重ねて2つの分かれ道を確認

## 5. 原画の形式
- 縦長1:2（長い辺は2000px前後が理想）、背景単体の1枚
- 住人・文字・記録・手紙・しおり・動く演出は描き込まない

## 決まったこと（主催者 2026-10-23）
- 図書館の絵本は、部屋（導入）で開く絵本と**同じ本**。外観・装丁をそろえ、図書館では最後のページがない状態で開かれている
- なぜ同じ絵本が図書館にあるのか、新しい説明やセリフは**追加しない**（シナリオは変えない。絵で同じ本だと分かるだけにする）

- 古い記録・手紙・しおりは背景原画に描き込まず、アプリ側の演出として重ねる（物語に書かれたタイミングで表示する）
