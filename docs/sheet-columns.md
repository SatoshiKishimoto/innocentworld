# スプレッドシートの列構成（多言語対応版・確定）

芽美のシナリオ制作用。**この列の順番のまま**データを作ってください（列の並びを変えるとプログラムが読めません）。

- 日本語の列は、これまでと同じ位置です。**ひらがな・Englishの列は各シートの右端に追加**しました（既存の列は動かしていません）。
- ひらがな・Englishが空欄のときは、その画面では日本語の文が代わりに表示されます。
- IDの列（場面ID・選択肢ID・施設IDなど）は3言語で共通です。言語ごとに行を分けず、**1行に3言語を並べて**書きます。表示言語を変えても分岐・集計は変わりません。
- `{name}` などの差し込みは、3言語どの列でも使えます。
- ひらがなの列は漢字を使わず、短く・やさしい言葉で書いてください（目安：1行70文字以内）。日本語は60文字、英語は140文字までが1画面の目安です（こえると自動でページが分かれます）。
- 「ことば」シートの正解は、ひらがな・英語など**複数の正解を ｜ で区切って1つのセルに**並べます（例：`ほしのかけら｜星のかけら｜star piece`）。大文字・小文字、全角・半角、カタカナ・ひらがなの違いは区別しません。
