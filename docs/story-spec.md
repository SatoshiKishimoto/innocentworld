# innocent world 物語システム 共同開発の取り決め

- 芽美（ChatGPT）：物語とゲームの設計（中身）
- Claude：Webアプリへの実装（仕組み・画面・AR）

芽美の設計を、下の書式で書いてもらえれば、Claude がそのままアプリに組み込みます。

**スプレッドシートに登録する正式な形式は docs/scenario-sheets.md を見てください。**（このページは考え方のまとめです）

## アプリの前提（設計のときに知っておいてほしいこと）

- 全体の構成は docs/system-design.md を参照。Googleサイト ＋ GitHub Pages ＋ Google Apps Script ＋ Googleスプレッドシート。
- QRコードは**入口の1つだけ**。各施設にはQRコードを置かず、日替わりの「ひみつのことば」を掲示する。
- 認証は二段階：①入口のことばで、その日の村の地図と物語を解放 ②施設のことばで、その施設の物語を解放。
- 一度解放した施設は、その日のあいだは再入力なしで読める。翌日は再入力が必要だが、前日までの選択・もちもの・進行は残る。
- ことばの正解判定はGAS側。正解のことばは公開コードに含めない。
- 表示条件を満たしていないときの案内は「施設に掲示されたひみつのことばを入力してください」。
- 住民登録・参加履歴・選択結果はスプレッドシートにも保存されるので、2日目・次回イベントの再訪判定、集計、機種変更時の復元ができる。
- 物語の最後は、既存のARパレード（通常版・クリスマス版）や花火を、別画面で開いてつなげられる。

## 芽美に書いてほしいもの

### 1. 住民登録・住民票

- 登録時に聞く項目（例：住民名、好きな色、どの住民キャラクターと仲良くなりたいか）
- 住民票に表示する項目と、住民番号の付け方
- 住民票のデザインの方向性（文章でOK）

### 2. ひみつのことば（スプレッドシートの「ことば」シートに入れます）

```
開催日, 施設ID, ひみつのことば, 正解したときのセリフ
2026-12-19, entrance, ほしのかけら, 「ようこそ、レンガ村へ！」
2026-12-19, well, みずのおと, 「井戸の底が、きらりと光った」
2026-12-20, entrance, ゆきのしずく, 「おかえりなさい」
```

### 3. 施設と物語（場面ごと）

場面ごとに、次の形で書いてください。

```
場面ID: well_01
場所: 村の井戸（ひみつのことばの掲示場所）
登場キャラクター: mimi
セリフ:
  mimi: 「井戸の底から、何か光ってるの……」
  mimi: 「いっしょにのぞいてみる？」
選択肢:
  A「のぞいてみる」 → 次の場面: well_02a  / 記録: 勇気+1
  B「やめておく」   → 次の場面: well_02b  / 記録: やさしさ+1
もらえるもの: 星のかけら（アイテム）
この場面を見られる条件: 井戸のひみつのことばを入力済み（ほかに条件があれば）
```

- 登場キャラクターは今のアプリにいる住民から選べます：esper, mimi, lily, luke, niko, hal, arika, nuru（ヌール／NOUR）, mock, jiiji
- セリフに `{name}` と書くと、住民登録したニックネームに置きかわります（例：「こんにちは、{name}！」）
  （新しいキャラクターも、画像があれば追加できます）
- 「記録」は、勇気・やさしさなどのポイントや、フラグ（〇〇を見た）として自由に決めてOKです。

### 4. 選択による分岐

- どの記録・ポイントによって、どの展開に変わるか

### 5. 2日目の再訪住民だけの物語

- 条件（例：1日目に住民登録済み＋2日目のひみつのことばを入力）
- 1日目の選択によって変わる部分があれば、その対応

### 6. エンディング

- エンディングの種類と、それぞれの条件
- 最後にどのARにつなぐか（例：パレード、クリスマスパレード、花火）

## 受け渡し方法

芽美の設計文を、そのまま Claude とのチャットに貼り付けてください。
書式が多少違っても Claude が読み取って組み込みます。分からない点は Claude から質問します。
