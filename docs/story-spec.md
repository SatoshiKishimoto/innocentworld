# innocent world 物語システム 共同開発の取り決め

- 芽美（ChatGPT）：物語とゲームの設計（中身）
- Claude：Webアプリへの実装（仕組み・画面・AR）

芽美の設計を、下の書式で書いてもらえれば、Claude がそのままアプリに組み込みます。

## アプリの前提（設計のときに知っておいてほしいこと）

- アプリはスマホのブラウザで動くWebページ（GitHub Pages）。**サーバーはありません。**
  - 住民票・進み具合・選んだ選択肢は、**来場者のスマホの中**に保存されます。
  - 同じスマホ・同じブラウザなら、2日目も「再訪した住民」として見分けられます。機種変更やブラウザの履歴削除をすると消えます。
  - 来場者どうしのデータ共有（ランキング、全員の投票結果など）は、サーバーを用意しない限りできません。
- 施設を「巡った」ことの確認は、**各施設に貼るQRコード**を読み取る方式にします（QRコードはClaudeが作ります）。
- 「ひみつのことば」は会場で口頭や掲示で伝え、アプリに入力してもらう方式です。
  - 詳しい人がページの中身を調べれば答えが分かる可能性はあります（遊びとしては十分な強さです）。
- 物語の最後は、既存のARパレード（通常版・クリスマス版）や花火につなげられます。

## 芽美に書いてほしいもの

### 1. 住民登録・住民票

- 登録時に聞く項目（例：住民名、好きな色、どの住民キャラクターと仲良くなりたいか）
- 住民票に表示する項目と、住民番号の付け方
- 住民票のデザインの方向性（文章でOK）

### 2. ひみつのことば

```
日付, ひみつのことば, 正解したときのセリフ, 解放されるもの
2026-12-19, ほしのかけら, 「ようこそ、レンガ村へ！」, 1日目の物語
2026-12-20, ゆきのしずく, 「おかえりなさい」, 2日目の物語
```

### 3. 施設と物語（場面ごと）

場面ごとに、次の形で書いてください。

```
場面ID: well_01
場所: 村の井戸（QRコード設置場所）
登場キャラクター: mimi
セリフ:
  mimi: 「井戸の底から、何か光ってるの……」
  mimi: 「いっしょにのぞいてみる？」
選択肢:
  A「のぞいてみる」 → 次の場面: well_02a  / 記録: 勇気+1
  B「やめておく」   → 次の場面: well_02b  / 記録: やさしさ+1
もらえるもの: 星のかけら（アイテム）
この場面を見られる条件: ひみつのことば（1日目）を入力済み
```

- 登場キャラクターは今のアプリにいる住民から選べます：esper, mimi, lily, luke, niko, hal, arika, nuru, mock, jiiji
  （新しいキャラクターも、画像があれば追加できます）
- 「記録」は、勇気・やさしさなどのポイントや、フラグ（〇〇を見た）として自由に決めてOKです。

### 4. 選択による分岐

- どの記録・ポイントによって、どの展開に変わるか

### 5. 2日目の再訪住民だけの物語

- 条件（例：1日目に住民登録済み＋2日目のひみつのことばを入力）
- 1日目の選択によって変わる部分があれば、その対応

### 6. エンディング

- エンディングの種類と、それぞれの条件
- 最後にどのARにつなぐか（例：パレード、クリスマスパレード、花火）

## 受け渡し方法

芽美の設計文を、そのまま Claude とのチャットに貼り付けてください。
書式が多少違っても Claude が読み取って組み込みます。分からない点は Claude から質問します。
