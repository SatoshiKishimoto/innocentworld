状態：仕様（未制作）。画風は docs/art-direction.md、共通の決まりごとは docs/art-arrival.md・story/art/guide-scene.png。
物語・設定は変更しない（以下は『消えた最後のページ』の今のシナリオからの整理）。

## 1. 物語の中の井戸
- 施設：**村の井戸**（id `well`）。説明「ミミが待つ古い井戸。水面には、ときどき文字のような光が浮かぶ。」
- 場面：`well_01` → 選択 → `well_02a`（気持ちを聞く）または `well_02b`（水面を調べる）。背景はすべて `well`
- 登場する住人：**ミミだけ**（地の文あり）
- 手に入るもの：**井戸の光**（`well_light`）「井戸の水面に浮かんだ、やさしい光。」

| 場面 | 出来事（背景にかかわる文） |
|---|---|
| well_01 1行目（地の文） | 「村のはずれに、古い井戸がありました。水面は空を映さず、静かに揺れています。」 |
| well_01 2〜5行目 | ミミ「大切な約束をしたはずなのに…思い出せないの」 |
| well_02a 3行目（地の文） | 「ミミはほっと息をつきました。井戸の水面に、小さな光がひとつ灯ります。」 |
| well_02b 1〜2行目（地の文） | 「井戸をのぞくと、水面にかすれた文字が浮かびました。」「『……かならず、また……』そこまで読んだところで、文字は消えました。」 |

## 2. 背景に必要な物
- **古い井戸**（主役）：石積みの丸い井戸。素朴な木の屋根と、つるべ（桶と縄）。施設の色は、屋根が茶色の木（#8a6a4a 近く）、石が灰色がかったベージュ（#cfc2ad 近く）
- **水面**：井戸の中が少し見える角度で描く。**空を映さない、深い青緑の静かな水**（鏡のように空や雲を映さない）
- **村のはずれ**：遠くに赤い屋根の家並みが小さく見える。手前は草地・野の花・小道。大きな木を1本（ミミのそばに静かな日陰）
- 雰囲気：到着や広場よりも**静かでやさしい**場面（ミミが悩みを打ち明ける）。明るい昼のままで、少し落ち着いた色
- **描かないもの**：住人（ミミ）、文字、水面の光や文字（光・文字はアプリが重ねる。3言語のため）、うさぎのモチーフ（ミミと混同されるため）

## 3. 画面の配置（座標は 400×800 の目安。画像では3倍）
| 範囲 | 何を置くか | 理由 |
|---|---|---|
| 縦 0〜56 | 空だけ | ボタンが重なる |
| 縦 56〜200 | 空・遠くの丘・小さな家並み | ― |
| 横110〜290・縦90〜425 | すっきりした景色（遠くの丘・木の葉・空） | ミミが立つ場所。ミミの絵は細身で、白い体なので、**白っぽい雲や明るすぎる背景をミミの後ろに置かない** |
| 横120〜280・縦420〜530 | **井戸のふちと水面**（主役） | ミミの足もとのすぐ前に井戸が来る＝ミミが井戸の向こうに立っているように見える。地の文の場面では井戸全体が見える |
| 縦530〜800 | 草地・小道の続き | 文章の枠が重なる |
| 左右 0〜30・370〜400 | 大事な物を置かない | 細長いスマホで切れる |

- 井戸の屋根とつるべは、ミミの左右（横110より左、または290より右）に柱が来るように。屋根がミミの頭の真後ろに重ならない形（屋根なしの井戸でもよい）
- 水面（井戸の口の内側）は、横150〜250・縦440〜500 あたりに、だ円で見えるように（アプリがここに光と文字を重ねる）

## 4. アプリ側の設定（原画が届いたら Claude が行う）
- `scenes.well = {far: 'art/scenes/well/far.webp', focus: 井戸のふちの下の端, keep: なし}`
- 375×667 では、井戸の水面が文章の枠の上に出るように背景をずらす
- 水面の光（`well_02a` の「小さな光がひとつ灯ります」）と、かすれた文字（`well_02b`）は、アプリが水面の位置に重ねて表示（文字は各言語の文）
- 住人の色味調整（characterTone）とのなじみを確認

## 5. 原画の形式
- 縦長1:2（例 887×1774 以上。できれば長い辺2000px前後）、背景単体の1枚（far）
- 住人・文字・水面の光は描き込まない
