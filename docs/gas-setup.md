# レンガ村の物語　サーバー（GAS＋スプレッドシート）の準備手順

所要時間：15分ほど。Google アカウント（innocent world 用のものがおすすめ）で行います。

> - 制作用（シナリオ共有）：ID `1ug5SUBHhA0AMOK_4ycuelBSEO_SsYd6LFXJyS4CUnqs`（見出しと見本の物語入り。GAS はつなげない）
> - 本番DB：ID `1h3Aa_4pnGTv0IL7haaFSQerOffJHqWJ_kpVo8ON9th4`（空。このファイルで下の 2. 以降を行う）

1. Google ドライブで「新規 → Google スプレッドシート」を作ります。名前の例：`innocent world 物語DB`
2. このスプレッドシートは**誰にも公開しないでください**（共有は運営メンバーだけ）。

## 2. プログラム（GAS）を貼り付ける

1. スプレッドシートのメニュー［拡張機能］→［Apps Script］を開きます。
2. 最初からある `コード.gs` の中身をすべて消します。
3. リポジトリの `gas/Code.gs` の中身をすべてコピーして貼り付け、保存（💾）します。
4. 上の関数の選択欄で **setup** を選び、［実行］を押します。
   - 初回は「承認が必要です」と出ます。自分のアカウントを選び、「詳細」→「（安全ではないページ）に移動」→「許可」を押します（自分で作ったプログラムなので問題ありません）。
5. スプレッドシートに戻ると、次のシートができています。
   - 中身用：イベント／開催日／ことば／施設／物語の入口／場面／セリフ／選択肢／アイテム／ポイント／住人／登録項目
   - 記録用：住民／復元コード／参加履歴／解放記録／進行／選択／状態／集計
   - 見本の物語（仮）が入っています。芽美のシナリオが届いたら差し替えます。

## 3. ウェブアプリとして公開する

1. Apps Script の右上［デプロイ］→［新しいデプロイ］
2. 歯車 → 種類「**ウェブアプリ**」
3. 設定
   - 説明：`レンガ村 v1`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. ［デプロイ］→ 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー
5. その URL を Claude に伝えてください。`story/config.js` に設定して公開します。

> プログラムを直したときは［デプロイ］→［デプロイを管理］→ 鉛筆 → バージョン「新バージョン」→［デプロイ］。URL は変わりません。

## 4. リハーサル（開催日以外に試す）

開催日以外は「今日はお休みです」と表示されます。リハーサルのときは次の手順で日付を固定します。

1. Apps Script の左の ⚙（プロジェクトの設定）→ 一番下「スクリプト プロパティ」→［プロパティを追加］
2. プロパティ `TEST_DATE`、値 `2026-12-19`（試したい開催日）→ 保存
3. **終わったら必ず `TEST_DATE` を削除**してください（残すと本番の日付判定が狂います）。

## 5. 物語やことばを編集したとき

- 物語の中身は5分間キャッシュ（一時保存）されます。すぐ反映したいときは、Apps Script で関数 **clearCache** を実行します。
- 列の順番は変えないでください。行の追加・削除は自由です。
- 「住民」「復元コード」「参加履歴」「解放記録」「進行」「選択」「状態」のシートは自動で書き込まれます。手で編集しないでください。

## 6. 集計を見る

「集計」シートに自動で表示されます。
- 住民登録者数／参加者数（のべ・実人数）／再訪した住民の数
- 開催日ごとの参加者数
- 施設ごとの解放数（開催日別）
- 選択肢ごとの人数
- 物語を読み終えた数

## 7. 無料枠の目安と注意

- 同時に処理できるのは30件まで（一般の Gmail アカウント）。入口で大勢が一斉に登録すると、少し待ちが出ることがあります。アプリは自動で1回送り直します。
- 1回の通信に1〜3秒かかることがあります。
- 会場の通信環境（Wi-Fi など）を事前に確認してください。ことばの判定と住民登録には通信が必要です。
- 毎回のイベントの前に、スプレッドシートを［ファイル］→［コピーを作成］でバックアップしておくと安心です。

## 8. Googleサイトへの組み込み

- 入口のQRコード → Googleサイトのページ
- Googleサイトでは、次のどちらか（両方でもOK）
  - **「レンガ村へ入る」ボタン**（おすすめ）：リンク先を `https://satoshikishimoto.github.io/innocentworld/story/` にする
  - **埋め込み**：［挿入］→［埋め込む］→「URLで埋め込む」に同じURLを入れる。埋め込みの中には「全画面で開く」ボタンが表示され、押すと住民票を引きついだまま全画面で開きます。
- ARは、物語のエンディングの「ARを見る」ボタンで、新しい画面に開きます。
- 入口のQRコードは `tools/make_qr.py` でGoogleサイトのURLから作れます（Claude が作ります）。
