# characters3/display/ ― ARパレードで表示する住人の絵

`characters3/` の標準素材（高さ1536px、`proto/characters3` ブランチで制作・正式採用）を、表示用に高さ1024pxへ縮小したもの。
iPhone での読み込みと画像メモリを軽くするため、ARパレード（`index.html`）はこちらを読む。

- 上下左右に高さの8%の透明な余白がある。足もと（いちばん下の点）は下の余白の線（下から8%）。
- `parade-lab/assets/chars3/` と同じ画像（試作ページで iPhone 実機確認済み）。
- これまでの絵 `characters2/` は削除していない。`index.html?chars=old` で、ARパレードをこれまでの絵に戻して表示できる。
- 物語（`story/`）は、これまでどおり `characters2/` を使う。
