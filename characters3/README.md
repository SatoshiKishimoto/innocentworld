# characters3/ ― ARパレード用 キャラクター標準素材

ARパレード（フロート・本番パレード）で使う住人の画像を、ここに標準素材としてそろえる。
既存パレードが使っている `characters2/` は**変更しない**（比較・復旧のため、そのまま残す）。

## 標準素材の仕様

| 項目 | 決まり |
|---|---|
| 元にする絵 | 公式イラスト。顔立ち・体形・色・装飾・持ち物を変えない |
| 構図 | 全身と持ち物（頭の飾り・耳・翼・尻尾・手足・杖・かばんなど）がすべて画像の中に収まる |
| 形式 | 背景透過のPNG（RGBA） |
| 大きさ | 高さ 1536px を目標（最低 1024px）。幅は絵に合わせる |
| 余白 | 上下左右に透明な余白。高さの 5% 以上（1536px なら約 77px）かつ 16px 以上 |
| 内側 | 目・口・歯・翼・服などの内側は不透明。半透明にしてよいのは、元の絵で半透明に描かれている部分だけ（例：ヌールの妖精の羽、光や煙の効果） |
| 輪郭 | 背景に接する 1〜3px だけをなめらか（アンチエイリアス）にする。白い縁取りは付けない |
| 足もと | 足の裏（いちばん下の点）を、画像の下端から余白ぶん上の位置にそろえる。表示ではこの線を地面に合わせる |
| 向き | 正面 `_front`、左を向いた斜め `_left`。右向きが必要なときは表示側で左右反転する（素材は作らない） |
| ファイル名 | `<名前>_<向き>.png`（例：`hal_left.png`、`mimi_front.png`）。名前は characters2/ と同じ英字 |

## 作り方の決まり

- 元の画像を単純に拡大しない。公式イラスト（設定画・三面図など）を基準にする。
- 欠けている部分を正確に戻せないときは、**推測で描き足さない**。ChatGPT で原画を作り直すための資料（どこが欠けているか、守るべき特徴）をそろえてから依頼する。
- 完成した素材は、自動検査（下記）を通したうえで、公式イラストと並べて目視で確認する。

## 受け取った画像を標準にそろえる

```
python3 tools/normalize_character_png.py 受け取った画像.png characters3/<名前>_<向き>.png
```

- 白い（単色の）背景は、外周からつながった部分だけを透明にする（目・歯など内側の白は残す）。
- 透明を表すチェック柄が絵として描き込まれている場合は `--bg checker`、周りに薄い光が付いた透過PNGは `--alpha-cut 40` を使う。
- 高さ1536px・上下左右の余白（標準は高さの8%）・足もとの位置をそろえ、最後に自動検査を行う。
- 元の絵が小さいと拡大になり画質が落ちるため、警告を出す（元の画像を大きく作ってもらうのが原則）。
- 拡大・縮小しても、内側の透明度は元のまま（目や歯は不透明のまま、妖精の羽など元から半透明の部分はそのまま）。

## 制作の依頼資料

`characters3/requests/<名前>_<向き>/` に、ChatGPTへ渡す参考画像（reference.png）と依頼文（prompt.md）を置く。

## 自動検査

```
python3 tools/check_character_png.py characters3/ --out characters3/_check
```

- 形式、解像度、余白、端への接触、内側の半透明、閉じた透明部分、足もとの位置を調べる。
- 「端に接している」は欠損の**疑い**であって、欠損と断定しない。最終判断は公式イラストとの目視比較で行う。
- 診断画像（`_check/*_check.png`）の見方：右半分の **赤い辺**＝端に長く接している、**オレンジの辺**＝少し接している、**ピンク**＝内側の半透明、**水色**＝閉じた透明部分、**緑の枠**＝必要な余白の線、**青い横線**＝足もと。

現在の `characters2/` の検査結果は [`docs/characters3-inspection.md`](../docs/characters3-inspection.md)。

## 完成基準（ハル2種・モック1種で確定）

1. 公式イラストの顔立ち・体形・色・装飾を変えない。ChatGPTで欠けた部分を描き足し、色の違いは画像編集で基準にそろえる（再生成で顔や形が変わるのを避ける）。
2. 全身と持ち物が画像内に収まる。透過PNG、高さ1536px、余白は高さの8%（123px）、足もとを下の余白の線にそろえる。
3. 体の内側に半透明の画素がない（元の絵で半透明の表現は除く）。白い縁取り・影・地面・文字なし。
4. 自動検査（`check_character_png.py`）が「問題なし」。
5. 元の絵・公式三面図と並べた比較画像で目視確認し、確認記録（`requests/<名前>/review.md`）に、同じ点・直った点・変わった点を残す。
6. ChatGPTの画像はチェック柄の背景や薄い光が付くことがある → `normalize_character_png.py`（`--bg checker`、`--alpha-cut`）で取り除く。
