既存のARパレード（`index.html`）とは別の試作ページです。既存のファイルは変更していません。

## URL の指定
`?view=side|front|back|far|bridge|close`、`?act=A|B|C`、`?night=0`（昼）、`?q=low`（軽量）、`?perf=1`（負荷を表示）、`?ui=public`（一般向けの画面：開発用の操作を出さない）、`?dev=0`（開発用の操作をたたんで開く）、`?speed=0.5`（AR走行の速さ m/秒。標準0.5、開発用の画面で「標準（ゆっくり）0.5／少し速く0.75／前の速さ1.15」を切りかえ）、`?t=10.4`（確認用：物語の時刻をその秒で止める）、`?chars=old`（住人をこれまでの絵で表示）、`?hal=auto|stand|run`（ハルの絵：自動＝動いているあいだは走る姿／立つ姿だけ／走る姿だけ）

住人の見本 `characters.html`：`?set=new|old|both`、`?hal=stand|run`、`?gap=2.2|0.9`（間隔）、`?one=hal`（1人ずつ表示の最初の住人）、`?move=0`（動きを止める）、`?grid=1`（0.5mごとの目盛り）、`?night=0`、`?speed=0.5`、`?t=秒`（確認用に時刻を止める）

## 画面の作り（一般向けと開発用を分けられる）
- 上の帯：題名・♪（音楽）・表示の切りかえ（ショールーム／AR走行）。一般向けにも残す部分。
- 下：物語の説明（一般向けにも残す）と、開発用の操作（`#devPanel`：見る位置・演出・照明・回転台・軽量・負荷）。開発用の要素には `dev` の印を付けてあり、`?ui=public` では表示しない。上の「操作」で開閉できる。高さの低い画面（スマホの横向き）では、最初はたたんだ状態で開く。
- カメラは、画面の大きさ・縦横比・上下の帯の高さから、見せたい範囲（フロート全体／橋と二人／二人のまわり）がちょうど収まる距離と位置を自動で決める。縦横を切りかえたときも合わせ直す。

## フロートの作り
- 車体：角の丸い台座の外周に、断面の形を引き伸ばして作った木部と金のふち（曲面）。側面は、スウェーデンの伝統的な花の絵付けを取り入れた独自の図案（彫った額縁の凹凸は法線マップ）。金の柱・ツタと花の垂れ飾り・角のランタン・電球。車輪は裾で隠す。
- 森：高低差のある地形（川の溝・向こう岸の丘・奥が高い舞台）、ねじれた幹の木3本（茂みは遠くで粗い形に切りかえるLOD、ふちに葉の房）、草・花・きのこ・小石・シダ、ふちを越える根と岩。
- 古い橋：フロートのまん中の舞台（長さ約2.2m・幅0.76m・弓の高さ0.36m）。板26枚・桁・石の土台・柱14本・木の手すり・たるんだロープ。親柱4本の上にランタン。風で全体がわずかに揺れ、板が波打ち、ロープがゆらゆら揺れる。手すりと足元に温かい電球、上から照らす光と足元にこぼれる光。橋の下の川は波と光の反射を描く水面。手前のふちから小さな滝が水盤へ落ちる。
- 観客の側から見て、木や飾りが橋と二人の前に来ないように配置（木は奥と向こう岸の丘）。反対側から見ても二人が隠れないよう、二人の後ろの木は幹を高くして茂みを頭より上にし、立ち位置からずらした。小さい木は橋の端の先へ移した。
- 照明：ランタンの点光源2つ（軽量モードでは使わない）、ガラスの発光、光のにじみ、電球、ほたる。
- 質感：木目・樹皮・石・苔・葉・絵付けを、その場で描くテクスチャと法線マップで表現（外部の画像を使わない）。
- 住人：公式画像をそのまま使う平面キャラクター。細かく分けた板を変形させて、かたむき・うなずき・ふるえ・はずみを付ける。外見は描き起こさない。
  - 絵はいつもカメラ（観客）の方を向き、裏側は見せない。
  - 物語の中で「ふり向く」ときも左右反転しない（板を細くして裏返す見え方をやめた）。相手の方へ寄る・かたむく・はねる、記号、照明で気持ちを見せる。
  - 左右反転は、カメラがフロートの反対側へ回ったときのハルだけ（橋の方を向いたままにするため）。境目で行き来しないよう余裕を持たせ、2枚の絵を0.3秒で重ねて入れ替える。
  - 記号（線と形だけで描く漫符）は補助。小さく短く、汗（A）・「！」（B）・ハート（C）の3回だけ。気持ちは動き・距離・橋の揺れ・照明で見せる。
  - 照明：こわい場面は橋の光が青白く暗くなり、ハルの色味も少し青白く。気づきの場面はモックに温かい光がさす。Cでは二人のまわりが温かく光る。

## 演出（24秒でくり返す）
二人とも最初から最後まで、橋の手前の同じ岸にいる（橋を渡らせる場面は作らない）。

| 時間 | 場面 | 動き |
|---|---|---|
| 0〜8秒 | A ためらい | 風が強まる。モックは「行こう」と橋の方へ身を乗り出してはずむ。ハルは橋をのぞき込み、勇気を出して片足を橋へ。その瞬間に突風で橋が大きく左右に揺れ、ロープが大きく振れ、板が波打ち、橋の明かりがちらついて青白く暗くなる。ハルは大きく一回、小さく一回とびのいて（片足の位置から約0.5m）、小さく丸まってふるえる。モックも思わず身を引く |
| 8〜14秒 | B 気づき | モックは橋から目を離し、ハルの方へ体を向けて、二段階でゆっくり近づく（二人の間 約1.1m → 約0.8m → 約0.6m）。ハルは少しずつ体を起こし、モックの方へかたむく。すぐそばでモックが目線を下げてうなずき、ハルは自分からモックへ寄って、うれしくて小さく2回はねる。二人の足もとに温かい光が広がり、橋の明かりも温かくもどる |
| 14〜21秒 | C 一緒にいる | 二人で同じ岸の川辺へ歩き、観客の方を向いたまま並んで、相手の方へ寄りかかる。ランタンが温かく輝き、向こう岸の花がひらき、ほたるが舞う。二人そろってはずみ、足もとの光が大きくなる |
| 21〜24秒 | もどる | 橋のたもとへもどる |

住人の動きは「姿勢」（立つ場所・かたむき・うなずき・ふるえ・はずみ・風にそよぐ・記号・色味）として台本が決め、見た目は別の関数が作る。将来3Dモデルにするときは、台本はそのままで見た目の部分だけを差しかえられる。

## 既存のパレードに組み込むとき（今回は組み込んでいない）
返す形は既存のフロートと同じ `{g, wheels, pts, people, len, update(t, dt, cheer)}`。組み込むときに必要な変更：
1. `createParade` の `lightUp(F)`（本体を暗くして電球で埋める処理）を、`F.noLightUp` のときは呼ばない。
2. 住人は自前で持つので、`riders` は指定しない。
3. `IWForestBridge.create({renderer, camera})` のように、描画とカメラを渡す（`const camera` は window から見えないため）。
4. 既存の場面の明かり（半球光1.25・太陽1.1）は、この試作の夜の明かりより明るい。組み込むときに明るさを合わせる。
